### Claude Code 작업 중 AI가 판단·제안하고 기록한 주요 결정
| 결정 | 근거(실제 확인 결과) |
|---|---|
| GIS건물통합정보는 자동 수집 불가로 기록, OSM 임시 + 명시 | data.go.kr 상세 페이지가 V-World 로그인 다운로드로 연결 |
| Overture 건물 높이 미사용 | 동성로 2,177동 중 height 0건 |
| 기상: NOAA ISD 47143/47142 | ISD 이력 목록에서 대구 현행 관측소 2곳 확인, 품질코드 필터 |
| Sentinel-2 날짜 2025-07-10 → 07-09 교체 | R003 궤도 커버리지 21% 진단 후 R103 궤도 99.9% |
| CARTO → OpenFreeMap | 타일 이미지에 ‘API KEY REQUIRED’ 워터마크 확인 |
| 건물 높이 0=결측, 층당 1.5~15 m 규칙 | 실제 SHP에서 1층·5,035 m, 1층·502 m 등 입력오류 확인 |
| 그림자 정수 차분 인코딩 | 공식 건물 적용 후 웹 그림자 116 MB → 42 MB, 복원 면적 오차 0 |

| UTCI 장파=기온 가정 명시 | 표면온도 자료 없음 — 임의 보정식 대신 가정·한계 공개 |
