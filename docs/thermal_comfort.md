# v1.4 야외 열쾌적성(UTCI) 적용 기록 (2026-11-11)

## P0-B 판정: UTCI 산출 가능성
**판정: "모델 추정 UTCI"는 산출 가능, 실측 검증은 불가.** 화면 전체에서 `모델 추정`·`시뮬레이션` 태그로 표시한다.

| UTCI 입력 | 확보 경로 | 성격 | 상태 |
|---|---|---|---|
| 기온·습도·풍속(10 m) | 오늘: 기상청 초단기실황·초단기예보 / 과거: 대구 ASOS 143(NOAA ISD) | 실황·예보·관측 | 확보 |
| 운량 | 오늘: 초단기예보 하늘상태(SKY) / 과거: ISD 전운량 관측(GF1, oktas) | 예보·관측 | 확보(관측 공백 시각은 추정 불가) |
| 일사(직달·산란) | Haurwitz 맑은하늘 → Kasten–Czeplak 운량 보정 → Erbs 분리 | **모의** | 일사 실측 없음(ASOS 일사는 지상관측 제외 결정으로 미사용) |
| 그늘 여부 | 건물 그림자 엔진(GIS건물통합정보 높이) | **모의** | 시범구역 2곳 |
| 평균복사온도(MRT) | T_air + ΔMRT(SolarCal, ASHRAE 55) | **모의** | 장파 = 기온 가정 |
| 정답(흑구온도·복사 실측) | 없음 | — | **검증 불가** |

## 계산 사슬 (`scripts/comfort/utci_model.py`, 모델 `utci-solarcal-v1`)
1. 태양 위치: NOAA 알고리즘 자체 구현(pvlib SPA 대비 고도 < 0.05°)
2. GHI_clear: Haurwitz(1945) — `pvlib.clearsky.haurwitz`
3. GHI = GHI_clear·(1 − 0.75·(N/8)^3.4): Kasten & Czeplak(1980), N=운량(oktas)
   - SKY 매핑: 맑음 2.0 / 구름많음 5.6 / 흐림 7.6 oktas(기상청 구간 중앙값), 강수(PTY>0) 8
4. DNI·DHI 분리: Erbs et al.(1982) — `pvlib.irradiance.erbs`
5. ΔMRT: SolarCal(Arens et al. 2015, ASHRAE 55 부록) — `pythermalcomfort.models.solar_gain`
   서 있는 사람, 흡수율 0.7, 하늘 시야 100 %, 보행 방향 0·45·90·135·180° 평균
   일조: 직달 노출(f_bes=1), 지면 반사율 0.2 / 그늘: 직달 차단(f_bes=0), 지면 반사 0
6. MRT = T_air + ΔMRT  ← **장파 가정**: 주변 표면 온도 = 기온
7. UTCI: Bröde et al.(2012) — `pythermalcomfort.models.utci`, 풍속 0.5~17 m/s 제한(플래그)

입력이 없으면 숫자를 만들지 않고 `insufficient_data`(예: 운량 관측 없음, 결측). 야간은 일조=그늘.
그늘로 기온을 임의 보정하는 식(예: −N °C)은 쓰지 않는다.

## 한계 (화면에도 표기)
- 장파 = 기온 가정 → 햇볕에 달궈진 포장·벽면의 복사 미반영 → **일조 UTCI 과소 가능**, 그늘 효과(ΔUTCI) 과소 가능
- SolarCal은 산란일사를 직달일사로부터 추정 → 흐린 날 산란 효과 과소
- 하늘 시야 100 % 가정(골목 협곡의 하늘 가림 미반영), 수목·차양 그늘 미반영
- 구역 하나에 한 지점의 기상값 적용(구역 내 기온·풍속 차이 미반영)
- 현장 흑구온도·복사 측정이 없어 **MRT/UTCI 정확도 미검증**

## AI (v1.4 §3.4 B안 — 예보 오차 보정)
- 정답: 같은 유효시각·격자의 기상청 초단기실황(관측소 실측 아님)
- 자료: 기상청이 실제 발표한 초단기예보 24건(2026-11-10 16:00 ~ 11-11 15:00, 공공데이터포털 서비스의 최근 1일 조회 기능으로 수신) × 8개 격자 = 984쌍
- 기준선: 원 예보, 학습기간 평균 편향 보정 / 모델: RandomForest(예보값·선행시간·시각·격자·직전 오차)
- 검증: 발표시각 기준 시간 분할(앞 70 % 학습, 뒤 30 % 평가)
- **결과(2026-11-11)**: 평가 216쌍 MAE — 원 예보 1.142, 평균편향 보정 0.943, **RF 1.665(악화)** → `insufficient`, 적용 안 함
- 적용 기준: 평가 ≥ 300쌍, 학습 ≥ 3일, 두 기준선보다 개선. 수집기가 매 회 재평가(`web/data/live/forecast_correction.json`)
- 선행시간별 예보 오차(실황 대비): +1 h MAE 0.99 °C → +6 h 2.13 °C, 편향 −0.1 → −0.9 °C(예보가 낮음)
- A안(MRT/UTCI 보정 학습)은 정답자료가 없어 **수행하지 않음**. 기존 Landsat ΔLST 공간패턴 모델(HISTORY > AI 분석)은 유지.
